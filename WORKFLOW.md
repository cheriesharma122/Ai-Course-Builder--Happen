# AI-Assisted Development Workflow

## Round 1 – Vague Prompt

I initially used a simple prompt asking the AI to create a settings form. The result was functional but lacked structure and missed important requirements like validation, accessibility, and project integration.

## Round 2 – Precise Prompt

I then used a detailed prompt specifying the required fields, validation, localStorage support, navigation updates, backend configuration, and design consistency. This produced a more organized and complete implementation.

## Comparison

The vague prompt generated a basic solution, while the precise prompt resulted in cleaner, more maintainable code with fewer manual corrections.

## Reflection

This exercise showed me that better prompts produce better AI-generated code. Clear requirements and constraints improve both the quality of the implementation and the development workflow.
